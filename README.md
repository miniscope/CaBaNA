# CaBaNA

**Ca**lcium **B**ehavioral **a**nd **N**eural **A**nalysis: a pipeline for asking
how neural activity relates to behavioral states.

`main` is empty for now while the code is reorganized. The code is on these branches:

- `gui-backup`: `main` as it was before 2026-11-06, with the Python package
  (`src/cabana`), its docs and tests, and the browser GUI (`gui/`).
- `backend-framework`: development branch of the Python package.

The GUI was built from a copy of [CaLab](https://github.com/miniscope/CaLab) taken at
commit [`06dcb34`](https://github.com/miniscope/CaLab/commit/06dcb34a6478fedfcea69fdd9a7819c3aa260fb8)
(`main`, 2026-10-03). The plan is to port it into CaLab soon.
